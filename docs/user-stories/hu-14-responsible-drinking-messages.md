## User Story

**As a** player,
**I want** light, non-preachy reminders to drink responsibly at the start and the end,
**So that** the game stays fun and safe and the stores see we take it seriously.

## Context

The age gate already carries a notice (HU-01). The PRD also asks for messages like "no manejes si tomaste" at natural moments. This story adds them consistently in the brand's voice.

## Acceptance Criteria

- [ ] The final ranking shows one short responsible-drinking line in the brand voice (for example about not driving), visually secondary.
- [ ] A rotating set of at least five such lines exists so repeat players don't see the same one every time.
- [ ] Messages never shame players and never use medical or legal tone.
- [ ] The age-gate notice and these lines share the same wording source.

## Out of Scope

- Drink counting or limits per player.
- Links to external resources.

## Business Value

Supports the 18+/Mature rating narrative and the brand's responsible stance at near-zero cost.
