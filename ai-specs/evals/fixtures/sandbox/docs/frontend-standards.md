# Frontend Standards (eval sandbox)

## Technology Stack

- Framework: **React**
- UI library: **`@flux-ui/core`** (Flux UI) — required for UI primitives
- Testing: Jest + React Testing Library
- File naming: **kebab-case**

## Components

- Place feature components under `src/components/<feature-name>/`
- Do not use Bootstrap, MUI, Chakra, or Ant Design
